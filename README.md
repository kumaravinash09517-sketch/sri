# sri - Sarkar AI Receptionist

This repository contains the core of the Sarkar AI Receptionist Android app (Agent SENSE -> THINK -> ACT).

Notes:
- Package: com.blurr.voice.v2
- Android min SDK: API 30+
- Gemini API endpoint is a placeholder in GeminiApi.kt; replace with your provider and API key.

Files added:
- AgentService.kt
- Perception.kt
- Agent.kt
- GeminiApi.kt
- ActionExecutor.kt
- AndroidManifest.xml
- res/xml/accessibility_service_config.xml
- res/values/strings.xml

Security:
- Do not commit real API keys to the repository. Use a secure keystore or server-side token exchange.
